## 보기

`index.html` 을 브라우저로 열면 됩니다. 별도 빌드 과정이 필요 없는 단일 HTML 파일입니다.

GitHub Pages로 배포하려면 저장소 **Settings → Pages → Branch: `main` / root** 로 설정하세요.
